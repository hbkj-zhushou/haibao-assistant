# 海宝车机助手 Android APK

捷途旅行者/山海T2等车型的车机管理工具。

## 功能
- Shell 命令执行
- APK 安装/卸载
- 文件管理
- 屏幕截图与控制
- 一键启动应用
- 设备控制（重启/关机）

## 下载 APK
在 GitHub Actions 构建完成后，转到 **Actions** 标签页，下载构建产物 `app-debug.apk`。

## 构建说明

### 本地构建
需要 Android SDK 和 Gradle：
```bash
./gradlew assembleDebug
```

### 云端构建
推送代码到 GitHub，自动触发 GitHub Actions 构建。
